Sobre mim

Sou estudante e desenvolvedor em formação, focado em compreender os princípios fundamentais da computação e da programação. Meu objetivo é transformar a curiosidade teórica em projetos funcionais, entendendo o que acontece em cada camada: desde a interface que o usuário vê até a infraestrutura de rede e a persistência dos dados no banco.

Tenho direcionado meus estudos práticos para o desenvolvimento de software, construção de APIs com Node.js, lógica orientada a objetos em Java e administração de redes. Não busco pular etapas: dedico tempo para aprender a estruturar soluções organizadas, utilizar controle de versão com Git e entender a arquitetura dos sistemas que construo.

Gosto de analisar problemas técnicos, documentar meus testes e aprimorar cada projeto conforme descubro melhores ferramentas e padrões de desenvolvimento.

✔ Foco em código limpo, semântico e estruturado
✔ Interesse integrado entre software, banco de dados e redes
✔ Evolução contínua por meio de projetos práticos e acadêmicos
